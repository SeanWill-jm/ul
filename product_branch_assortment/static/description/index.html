Product Branch Assortment

Version: 19.0.1.0.3 · Last Updated: 2026-10-07 · Copyright © 2026 SWIT Global Consultants · Created by: SWIT Global Consultants

Purpose

Lets the parent company buy every product centrally while each branch sells and stocks only the products assigned to it. Standard Odoo offers one Company field per product and it is either/or; this module adds a separate Allowed Branches list. Products are never hidden: a branch outside the list can still see the product, receive it in reports and transfers, but cannot sell it, receive it into its own stock or set a reordering rule for it. A branch that already holds stock may sell it down.

Setup (Administrator)

  1. Install the module (Apps › Product Branch Assortment). Requires Sales and Inventory.
  2. Keep every product's Company set to the parent company or blank. That is what lets the parent purchase for all branches.
  3. On branch-specific products, set Allowed Branches. Leave it empty on products every branch may sell.
  4. Bulk: Inventory › Products › list › select › multi-edit Allowed Branches, or import a CSV with id (External ID) and allowed_branch_ids (branch names, comma-separated). A sample is in migration_templates/.
  5. POS: use the standard Restrict Categories on each register; this module does not change POS.

User guide

Sales. The product picker on a quotation only proposes products in the order company's assortment. A product typed or imported outside it is refused with a message naming the product, the branch and the allowed branches.

Inventory. Receipts, inbound transfers and positive adjustments into a branch outside the assortment are refused. Deliveries, internal relocations within the branch and customer returns always go through. Reordering rules for non-allowed products are refused and the Replenishment report does not propose them.

Purchasing (parent). Unchanged: every product can be ordered at the parent.

Everyone. Product lists open on "My branch's assortment". Click the chip to see all products; use the "In / Outside my branch's assortment" filters to switch.

Behaviour and limits

  • A listed branch covers its sub-branches; the parent is always allowed.
  • Sell-down: a branch removed from a product keeps selling its on-hand stock; new receipts and reorders stop.
  • Assortment is per product, not per category. Products sold in two branches need both branches listed.
  • No record rule is added, so cross-branch reports, valuations and transfers keep working.
