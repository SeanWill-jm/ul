Partner Account Number

Version: 19.0.1.0.9 · Last Updated: 2026-10-07 · Copyright © 2026 SWIT Global Consultants · Created by: SWIT Global Consultants

Purpose

Gives every customer and vendor a branch-prefixed account number in the form PPP-NNNNNN: PPP is the three-digit prefix of the branch (company) that owns the account, NNNNNN is a six-digit number that is unique across all branches. Numbers issued by Odoo start at 062001; numbers migrated from ManageMore keep their value, normalised to the same format. Once issued, a number is never changed, reused or deleted.

Setup (Administrator)

  1. Install the module (Apps › Partner Account Number).
  2. Settings › Users & Companies › Companies: open each branch that issues accounts and set Account Prefix (e.g. 101, 102, 103). A prefix can belong to one branch only.
  3. Nothing else to configure. The global sequence (partner.account.number) is created by the module and starts at 062001.

User guide

Sales / Purchase users. On a new contact, pick a Customer Type and save: Odoo fills Customer Account No. with the next free number for the branch you are currently working in. To record an existing number, type it in Customer Account No. before saving; the branch is inferred from its prefix.

Administrators. The number and its branch cannot be edited or cleared after saving, and a numbered contact cannot be deleted; archive it instead. Archived contacts still count for uniqueness. Contacts list and search have an Account No. column and filter; the Legacy Account No. filter lists migrated contacts.

Imports (CSV)

Columns: External ID, Name, Customer Type, Account Branch/External ID, Customer Account No. Rules applied on import:

  • Canonical values (103-061900) are stored as they are.
  • Legacy values are normalised: a prefix that belongs to a branch is kept (101-36798 → 101-036798); a missing or unassigned prefix takes the company selected in the switcher while importing (30007 → 103-030007 when importing in branch 103). Dash-less exports are split as prefix + suffix (10240048 → 102-040048). The original value goes to Legacy Account No.
  • Import each branch's legacy file while that branch is the current company.
  • A supplied Account Branch must match the prefix in the value; duplicates are rejected with the row number.

Behaviour and limits

  • If a migrated number occupies a future sequence value, the generator skips it.
  • Legacy numbers live in 000000–061999; new numbers start at 062001, so the two ranges never collide.
  • Uniqueness and prefix checks run globally, regardless of which companies the user has enabled.
