# Installation Notes

The ZIP contains the installable addon folder `partner_account_number/`.

Target: **Odoo.sh 19.0**.

The package is statically checked for Python syntax and XML well-formedness before delivery. It still must be installed and UAT-tested in an Odoo.sh development branch because this build environment is not a running Odoo 19 server/database.

See `partner_account_number/README.md` for configuration and CSV migration instructions.
