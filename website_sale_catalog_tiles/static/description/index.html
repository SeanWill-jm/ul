eCommerce Catalog Tiles

Version: 19.0.1.0.1 · Last Updated: 2026-10-07 · Copyright © 2026 SWIT Global Consultants · Created by: SWIT Global Consultants

Purpose

Gives the web shop's product grid the look of the Sales app's Catalog view: every product tile shows the internal reference (SKU), the on-hand quantity in the website's warehouse, and a quantity field with − / + buttons next to Add to Cart, so the quantity chosen on the tile goes straight into the cart with no pop-up. Each element can be switched on or off per website, and the on-hand quantity can be shown to logged-in customers only, which suits an invitation-only wholesale site.

Setup (Administrator)

  1. Install the module (Apps › eCommerce Catalog Tiles). Requires Website, eCommerce and Inventory.
  2. Website › Configuration › Settings: pick the website at the top, scroll to eCommerce › Catalog Tiles, set the three switches, Save. Repeat for each website.
  3. Website › Configuration › Settings › Inventory: set the website's Warehouse; the on-hand figure is that warehouse's available quantity. Empty means all warehouses of the website's company.
  4. Per product (Sales tab): "Sell when Out-of-Stock" and "Show availability Qty" keep their standard meaning; when out-of-stock sales are off, the tile picker's maximum is the available quantity.

User guide

Customers and sales reps on the shop. Under each product name: the SKU, then "7 On Hand" in green or "0 On Hand" in red ("· order anyway" when the product may be sold out of stock). Type a quantity or use − / +, then Add to Cart; the cart receives that quantity. Configurable products still open the standard configurator with the quantity passed in.

Website editor. The usual tile options (columns, image ratio, description) still apply; the module's elements sit inside the standard tile and follow the theme.

Behaviour and limits

  • Stock is read the same way as the standard product page (website warehouse), under a read-only elevated call because visitors cannot read stock records; only the rounded-down number is shown.
  • Stock is computed per tile; fine at the default products-per-page, revisit above ~40 per page.
  • The picker is not added to the product page, which already has one.
