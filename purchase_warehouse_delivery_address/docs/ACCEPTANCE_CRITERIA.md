- [ ] Module installs on Odoo.sh 19.0 without error.
- [ ] Standard **Deliver To** remains the only warehouse destination selector.
- [ ] Selecting a warehouse resolves the correct address.
- [ ] PO form displays read-only Delivery Address.
- [ ] RFQ PDF prints Delivery Address.
- [ ] Confirmed PO PDF prints Delivery Address.
- [ ] Receipt uses the same warehouse selected by Deliver To.
- [ ] Changing Deliver To changes the address.
- [ ] Dropship behavior is not duplicated or overridden.
- [ ] Security/multi-company behavior remains standard.
- [ ] Staging UAT is approved before Production.
