# Buyer User Guide

1. Go to **Purchase → Orders → Requests for Quotation**.
2. Click **New**.
3. Select the Vendor.
4. Add products.
5. Select the required receiving warehouse/operation under **Deliver To**.
6. Review the read-only **Delivery Address**.
7. Save.
8. Print the RFQ or confirmed Purchase Order.
9. Verify the Delivery Address before sending the document to the vendor.

To change destination, change **Deliver To**. Do not attempt to maintain a separate address.

If the address is wrong, correct the Warehouse **Address** under Inventory configuration and reprint.
