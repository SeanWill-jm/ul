# Buyer User Guide (19.0.1.0.1)

1. **Purchase -> Orders -> Requests for Quotation -> New**.
2. Select the Vendor and add products.
3. Select **Delivery Address** (left column, under Currency). Only contacts tagged
   **PO Delivery Address** are listed.
4. Save. Print the RFQ or Purchase Order and check the "Delivery Address" block.

Notes:

- **Deliver To** (right column) still controls the receiving operation. Delivery Address does
  not change it.
- Delivery Address can be changed at any time, also after confirmation. Reprint and resend if
  the vendor already holds an earlier PDF.
- Clear the field to print the standard document.
- When a Delivery Address is chosen, the standard **Shipping address** (Dropship Address) block is not printed. Real dropship orders: leave Delivery Address empty.
- The vendor's tax number prints as **TAX ID:** on the RFQ and PO.
- Need a new site? Ask the contact administrator to create the contact and tag it
  **PO Delivery Address**.
