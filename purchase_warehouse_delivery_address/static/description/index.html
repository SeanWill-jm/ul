Purchase Delivery Address

Version: 19.0.1.0.5 · Last Updated: 2026-10-07 · Copyright © 2026 SWIT Global Consultants · Created by: SWIT Global Consultants

Purpose

Adds an editable Delivery Address to Requests for Quotation and Purchase Orders, chosen from contacts tagged PO Delivery Address, and prints it as a block on the RFQ and PO PDFs so the vendor knows where to ship. The standard Deliver To (receiving operation), Dropship Address and the receipt created on confirmation are not changed; when the field is empty the documents print exactly as standard Odoo does.

Setup (Administrator)

  1. Install the module (Apps › Purchase Delivery Address). Requires Purchase and Inventory.
  2. Contacts: open each delivery site (warehouse, store, job site) and add the tag PO Delivery Address. Only tagged contacts appear in the dropdown.
  3. No other configuration. Report layout follows the company's standard document layout.

User guide

Purchasing. On an RFQ, pick the site in Delivery Address. Print or email the RFQ / PO: the address block appears on the PDF and on the vendor's portal page. The field can be changed later, including on confirmed orders; the change is logged in the chatter.

Administrators. Removing the tag from a contact later never blocks edits on orders that already reference it; the check only runs when the field is set or imported. The RFQ/PO lists can be grouped by Delivery Address.

Imports (CSV)

Column Delivery Address (or po_delivery_address_id/id) on purchase order imports; the referenced contact must carry the tag or the row is rejected.

Behaviour and limits

  • Does not change where goods are received (Deliver To) or any stock move.
  • Email bodies are untouched; the PDF attachment carries the block.
  • Technical name purchase_warehouse_delivery_address kept from 1.0.0 so installations upgrade in place.
